# 手動確認チェックリスト（動的モジュール列 / frontend）

自動テスト（`node --test`）で担保できない、実ブラウザでの表示挙動の確認項目。
設計書 §8 の V1〜V10 に対応する。

| # | 手順 | 期待結果 |
|---|---|---|
| V1 | `?d=` なしで `index.html` を開く。`#operators-head-row` の `<th>` 数を数える | 14。最後の `<th>` のテキストが `Module B` |
| V2 | 同上。`#operators-body tr` の数を数える | 0（現行どおり） |
| V3 | `?d=<既存の旧形式ドキュメント>` を開く。`#operators-body tr` の数を数える | 423（+ マスター外コードがあればその件数） |
| V4 | 同上。`-` を表示しているセル総数 | 1628 |
| V5 | 同上。数値を表示しているモジュールセル総数 | 487（V4+V5 = 423×5 = 2115 が常に成立） |
| V6 | `KZ08`（ムリナール）の行 | モジュール列5つすべて `-` |
| V7 | `RL03`（イフリータ）の行 | X列・D列は数値、Y列・A列・B列は `-` |
| V8 | `RE10`（レイディアン）の行（旧共有データ = `moduleB` キーなし） | A列は共有データの値、B列は `0`（`-` ではない） |
| V9 | データ取得失敗時のエラー行の `colSpan` | 14（`thead` の `<th>` 数と一致） |
| V10 | 言語ラジオを3回切り替えた後の `<th>` 数 | 14（増えない） |

V4/V5 のカウント方法（DevTools コンソール）:

```js
[...document.querySelectorAll('#operators-body td')].filter(td => td.textContent === '-').length
```
